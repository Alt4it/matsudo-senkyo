# c042 照合結果
## 書き写しの問題
- b04：「②合計で150億円以上の削減を目指します!」→画像（拡大1）では「①②合計で150億円以上の削減を目指します!」。①だけが落ちている。①②は行頭の箇条番号ではなく「①と②の合計」の意味なので、「①②合計で…」と写すべき（少なくとも②だけを残すのは誤り）。
- b05：verbatim の先頭の「（表）」は紙面にない語（書き写し担当の注記）。verbatim は原文だけにし、表であることは issues に書く。

## 分類の食い違い
- b08：A=gyozaisei / B=machi+gyozaisei（意見：本文は「赤字販売は許さない!販売計画の見直しを!」だけで、まちづくりの語がない。B の machi は b06 の文脈（マンション）から補ったもので、本文に明記がない。A が基準に合う）
- b17：A=fukushi / B=fukushi+machi（意見：本文に「バス」「タクシー料金助成」と明記があり、machi の基準「バス」に当たるので B も成り立つ。B は c035 b13 と揃えたとしている。他の候補者の同種の公約（高齢者の交通費助成）と揃えて決めてください）
- b15・b16：テーマの組は同じ（other・machi）だが順序が逆（A=other→machi / B=machi→other）。主テーマに意味があるなら揃える必要あり。c039 b05・b06（B によると machi+other）と揃えるなら B の順序。
- achievement：全ブロックで一致（すべて false）。

## 要約の問題
- b14（A）：「21世紀の森と広場のペットエリアを増設」。原文は「21世紀の森と広場、ペットエリアの増設」で、読点を「の」に変え、「森と広場の中のペットエリア」と関係を決めてしまっている。B（「21世紀の森と広場、ペットエリアの増設」）のほうが原文に沿う。
- b11（A）：「避難所など市施設へ」。原文は「市施設（避難所）へ」で、「など」を足したことで避難所が例の1つになり、関係が変わっている。「無料設置」も落ちている。B（「…無料設置を市施設（避難所）へ拡大」）のほうが原文に沿う。

## 人に判断してほしいこと
- b09・b10 の区切り：◆の小見出しの下にある別々の行（b09「入札改革!ごみ収集事業など随意契約の見直し」と「防犯カメラ付き防犯灯の導入で、初期費用を10分の1に!」、b10「市有車を週末、市民へ貸し出し」と「広告事業の強化!ネーミングライツ導入など」）を1ブロックにまとめている。行ごとに別の施策で、テーマも分かれる（防犯灯→bousai）。schema の「箇条1つ＝1ブロック」に照らすと、行ごとに分けるほうが基準に合うと考える。小見出し（「行政改革の断行!」「収入増加策の実施」）は見出しと同じ扱いになる。
- b08 と b06 の重複：b06「…販売計画の見直し」と b08「…販売計画の見直しを!」は同じ語句。schema の「同じ語句の重複は1回だけ政策にする」に当たるか確認してください（b08 には「赤字販売は許さない!」という主張が加わっている）。
