## 分類の食い違い
- b05：A=other / B=fukushi（意見：本文は「女性が自立した生活できるよう支援強化を」で、themes.json の fukushi の例（高齢者・障害者・介護・医療・健康づくり・生活困窮者支援）に当たる語は書かれていない。生活困窮者支援とみなすのは推測になるので、A の other が基準に近い）
- b06：A=gyozaisei / B=machi（意見：本文に「現地建替えの新庁舎」とあり、themes.json の machi「公共施設の整備や建て替え」に明記で当たる。一方、求めている内容は「仮庁舎の業務は市民に配慮を」で、行政の業務の進め方とも読める。どちらも本文に根拠があるので、machi と gyozaisei の2テーマにする案も含めて人が判断してほしい）
- b07：A=bousai, kankyo / B=kankyo, bousai（並び順だけの違い。本文に「気候危機」「災害増」の両方が明記されており、2テーマはどちらも基準どおり）
- b09：A=other / B=gyozaisei（意見：本文は国の法人税・消費税について市議会から声を上げる主張で、themes.json の gyozaisei は「市の財政・行政改革…」なので当たらない。B 自身も notes で市の財政ではないと書いている。A の other が基準に合う）

## 要約の問題
- b07（A・B とも）：「気候危機・災害増に想定以上の対策強化を」は具体的な施策・数値・期限が書かれておらず、A・B とも抽象的として要約を空にした b01「物価高騰から市民生活を守る対策強化を」と同じ程度の具体性。b01 は空、b07 は要約ありと扱いが分かれているので、b07 も空にするのが基準に近いと考える。

## 人に判断してほしいこと
- kana「くどうすず」：ふりがなは「工藤」の「くどう」だけで、名の「すず」は氏名のかな部分、「子」には読みがない。schema.md どおり読みの分かる「すず」までつないでいるが、画面上は「くどうすず」が全体の読みのように見えるおそれがある。「くどうすず」のままにするか、姓だけの「くどう」にとどめるか決めてほしい（書き写し担当も確認を求めている）。
- b10「誰もが差別なく平和に安心・安全の松戸市政を！」は本文より明らかに大きいが slogan の帯より小さいので message にしている。基準どおりと考えるが確認してほしい。
- b08「老朽化進む学校施設、教育環境の整備優先を」は A・B とも kosodate のみ。学校施設の整備として machi（公共施設の整備）を付けるかどうか、c058 b06（雨漏り校舎の修繕）などほかの候補者の扱いとそろえてほしい。
