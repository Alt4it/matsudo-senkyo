# c033 照合結果

## 書き写しの問題
問題なし（上部黒帯、2行目、8つの囲み（見出しと本文）、プロフィール全項目を拡大画像と文字単位で照合し、相違は見つからなかった。数字（16年間・8年間・36回・600床・549床・2年前倒し・100%・昭和32年4月・平成22年11月・4期目・第18期）も一致。kana=null は姓「大橋」にふりがながないため schema どおり。党派・年齢の記載なしも画像どおりで、年齢を生年から計算していない。隣の候補者の混入やブロックの抜けもない。kind の振り分け（b04・b11 は本人の活動の説明で profile、b06 は訴えで message、b13 は本人の活動と現状説明で message。同じ見出しの下に施策の文 b14 があるので外してよい）は基準に合う）

## 分類の食い違い
- b20：A=machi／B=machi＋fukushi（意見：本文は「各駅バリアフリー100%実現を推進します。」で、高齢者・障害者などの明記がない。Bは notes で見出し「医療・福祉の充実」も根拠にしており、「見出しからの推測で足さない」に反する。machi だけのAが基準に合う）
- 要約の言い回しだけが違うもの（テーマ・achievement は一致）：b07、b09、b12、b14、b16、b18。どれも原文の範囲内だが、b14 は下記のとおりAの方が原文から離れている
- achievement：全ブロックで A・B 一致

## 要約の問題
- b03（A・B共通）：「新庁舎整備で…」の「新庁舎」は見出し「新庁舎整備事業について」から補った語で、本文には「新庁舎」がない（本文は「新築を想定した整備の際には」）。heading から対象を補っている
- b14（A）：「嘘のない「待機児童ゼロ」を必ず実現」は、原文「必ず実現させたいと思います」の希望の言い方を言い切りに変えている。B の「…必ず実現させたい」の方が原文に近い
- b01（A・B共通）：「引きつづき松戸市財政・経費縮減に取り組む」は、具体的な施策・数値・期限のない方針とも読める。c031 b01（行財政改革）の扱いと揃えて、要約を付けるか空にするか決める必要がある（下記「人に判断してほしいこと」にも記載）

## 人に判断してほしいこと
- slogan：書き写し担当は上部の黒帯「大橋ひろしは引きつづき・松戸市財政・経費縮減に取り組みます」を採っている。拡大画像では2行目の「大橋ひろしは即行動します」の文字の方が黒帯の文字とほぼ同じか少し大きく見え、どちらが「最も大きい」か判断が分かれる。「同じ大きさなら上」の規則で黒帯を採るかどうか
- career「4期目」：プロフィール「松戸市議会議員（平成22年11月初当選・4期目）」から括弧内の末尾だけを抜き出している。単独では何の4期目か分からない（c031 の「三期目当選」と同じ問題）。全候補者でどこまで抜き出すか揃えてほしい
- b11（profile）／b12（policy）：「松戸市政実話リポート」の発行は本人の活動とも読める。b12「今後も…追究し…ご報告していきます」を政策（gyozaisei＝情報公開）とするか、候補者自身の活動として profile／message にするか（書き写し担当・Aとも要判断としている）
- b08：本文「今後も「危険」「不便」「迷惑」を徹底的に解消すべく全力を尽くします。」には防犯・安全の語がなく、bousai は見出し「防犯・安全対策」からの推測（A・Bとも notes で認めている）。施策・対象も書かれていないので、要約が空なのは基準どおり
- b18「歩け歩け・グランドゴルフを応援」：本文に健康・高齢者の語がなく、fukushi は見出し「医療・福祉の充実」からの推測。基準どおりならスポーツとして other。A・Bとも fukushi・low
- b16「下水道施設整備」：themes.json の基準に下水道の明記がない。A・Bとも machi で一致しているが、kankyo の可能性もある（Aは low）。テーマ定義に下水道を入れるか決めてほしい
- b05「今年度ようやく…600床から549床に削減し、経費削減に取り組んでいます。」：済んだこと（削減し）と継続中のこと（取り組んでいます）が1文にある。A・Bとも achievement=true だが、schema の「実績と今後の話が同じ文に混ざる場合は false」に当たるかどうか（継続中は「今後」ではないと読めば true でよい）。主語が書かれていない点も、実績の印を付けてよいか確認してほしい
