# c001 照合結果
## 書き写しの問題
- b02：「介護不安の解消し、移動手段の助成」→画像では「介護不安の解消、移動手段の助成」（「し」が余分。原文にない文字の混入）

確認済みで問題がなかった点：氏名・ふりがな（にかいどうつよし）・党派、数字（61%、57%、78%、26ヵ所、96回、5,200部、年号、第22期、9期目、孫7人）、ブロックの抜けなし、隣の候補者の文字の混入なし。age・status が null なのは正しい（公報に年齢・「現職」等の明記なし。「9期目当選」「1954年」からの推測も入っていない）。

## 分類の食い違い
問題なし（全ブロックでA・Bのテーマが一致）

## 要約の問題
40字超過はなし（最長はAのb08で39字）。
- b01（A・B）：原文「長崎市の平和大使派遣」を、Aは「長崎への」、Bは「長崎市への」と言い換えている。派遣先と読むのは解釈が入るため、「長崎市の平和大使派遣の継続」に寄せるのが安全
- b03（B）：「学校のエアコン・トイレ洋式化等の施設整備」は、エアコンがこれからの整備に読める。原文は「エアコン設置にPFI方式を提案し全校設置」で設置済みの書き方
- b04（B）：「労働相談の充実、就労支援」が今後の公約に読める。原文は「補助を実現してきましたが」と続き、実績として書かれている（Aは「実績」と区別できている）
- b05（A・B）：見出しの柱「原発に頼らない街づくり」が両案とも要約から抜けている。候補者が見出しに掲げた主張なので、残すことを検討してほしい
- b05（A）：「災害弱者対策を充実」が抜けている（Bにはある）
- b06（A）：「新八柱駅周辺整備」は原文「周辺道路整備」から「道路」が落ち、整備の範囲が広く読める
- b06（A・B）：見出しの「公共交通の利用助成」が両案とも抜けている
- b07（A）：「市立総合医療センターで医療体制」は文として意味が不完全。原文は「安心医療体制」「体制促進」

## 人に判断してほしいこと
- issues の b08「新聞未購読者」：画像でも「未」に見える（候補は「未」）。字が小さいので、公報PDFの拡大で確認してほしい
- issues の b09：実績の列挙を policy として扱うか。c002 の b01・b02 と同じ判断にする必要がある（公平性）
- issues の slogan：「実現しました！」を見出しとして null にしたのは、c002 で b01 冒頭の一文を slogan にした扱いと基準が揃っていない。全候補者で基準を決めてほしい（公平性）
- b09 のテーマ：3テーマに各2件ずつまたがり、上限2つのためA・Bとも machi を外した。外す根拠は件数からは出ない。八柱駅南口と市民センターのバリアフリー化がまちづくりの分類から漏れるので、項目ごとに分けるなどの扱いを検討してほしい（公平性）
- b09 の要約：A・Bとも6項目のうち「子どもの貧困対策ガイドブック」「市民センターのバリアフリー化」が要約から落ちている。要約だけでは伝わらないので、原文の併記を検討してほしい（公平性）
- b03 のテーマ：「スポーツ施設整備」は基準では other（文化・スポーツ）に当たる可能性がある。A・Bとも kosodate のみ。意見：学校の施設整備の文脈とも読めるが、学校施設と明記はないので確認が必要
- b06 のテーマ：「JR駅ホームドア設置促進」をA・Bとも machi にしている一方、c003 b04 のホームドアはA・Bとも bousai。候補者間で扱いが違う。意見：c001 はバリアフリー、c003 は安全の見出しの下なので文脈の差はあるが、揃えるかどうかは人が決めてほしい（公平性）
- b10 の「欅クラブ」：字が小さく、書き起こしの読みで合っていると見るが、PDFの拡大で確認してほしい
- source.pages：全候補者で 2 だが、紙面の表示は「(1頁/8頁)」。サイトに出すページ番号をPDFの枚数と紙面の表示のどちらにするか決めてほしい（c002〜c004 も同じ）
