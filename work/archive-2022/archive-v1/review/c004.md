## 人に判断してほしいこと
- issues の kana：ふりがなは「大和山」の分のみで「おおわやま」と画像で確認した。「太郎」にふりがなはない。kana をこのままにするか、表示方法は c003 と合わせて決めてほしい（公平性）
- issues の b05「やまと学院.」：画像でも「院」の直後に点が見える（候補は「やまと学院.」で、書き起こしどおり）。汚れの可能性を消すため、公報PDFの拡大で確認してほしい
- b04 のテーマ：A・Bとも machi + kankyo。「新・クリーンセンター」の用途は公報に書かれていない。ごみ関連と読むのは名称からの推測で、公報以外の知識が入る余地がある。意見：公共施設として machi のみが基準上は安全。kankyo を付けるかは人が決めてほしい
- b02〜b04 の kind：各ブロックの冒頭に「六高台で塾長25年」「只今、母を介護中」「生涯六実っ子宣言」が入っている。経歴・訴えの性格の札で、政策そのものではない。要約には入っていないので害はないが、verbatim に含めたままでよいか確認してほしい
- b01 の kind：「いじめ110番」は message に含まれるが、同じ語が b02 の policy にあるので、政策の分類からは漏れていない
- slogan：「笑顔計画」は画像で最大の文字と確認した。全候補者の基準を揃える話は c002 を参照
- 公平性：policy は3件で要約も短いが、公報の記載量どおりで、手順による偏りではない。ただし公約が短句のみのため、他の候補者に比べ要約と原文がほぼ同じ分量になる
