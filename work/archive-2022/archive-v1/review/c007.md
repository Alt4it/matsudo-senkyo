## 人に判断してほしいこと
- b01「毎赤字の穴埋めに」：画像でも「毎赤字」と読め、×印の重なりで隠れている文字も見当たらない。候補は「毎赤字」のまま（「毎年赤字」の脱字の可能性はあるが、原文を改変しない方針なので直さない）。原本PDFでの確認を勧める
- b04 の氏名の漢字：画像では「鴈野 聡」に見える。候補は「鴈」（字形の似た「雁」ではなさそうだが細部は人の確認が必要）。候補者に不利に働きうる箇所なので、原本PDFの拡大で確認してほしい
- kana が null で、name 自体がひらがな。漢字表記「鴈野 聡」を氏名欄に併記するか決めてほしい。また五十音順では kana ではなく name を使う必要がある（他の候補者は部分的な kana のみ）
- 年齢と status：age は「昭和44年生まれ」、status は「松戸市議会議員1期」の記載のみ。公報に明記がないので null は妥当だが、年齢を明記した候補者と表示の差が出る。生年や期数を計算・推測せずに、どう見せるかを決めてほしい
- b02 の kind：「実績」は過去の成果で、schema の policy（政策・公約）に厳密には当たらない。一方、policy から外すと財政テーマの比較から消える。意見：実績の扱いを全候補者で統一する規則が必要
- 【公平性】b03「民間にできることは、民間に。」が kind=message で分類対象外。紙面で大きく強調され、行財政の方針とも読める。意見：policy に変えて gyozaisei を付ける余地がある。なお、この候補者の分類対象は2ブロックのみ（紙面自体の政策項目が少ないことによる）
- b01 の verbatim：×印と○印は本文に含まれず、「赤字の穴埋め不要」「病院は残ります」がどちらの建物の話かが文字だけでは伝わりにくい。読み順も紙面に明示がない。サイトで公報画像を併記するなどの要否を判断してほしい
