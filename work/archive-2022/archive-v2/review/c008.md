# c008 照合結果
## 書き写しの問題
氏名・読み（とばり＋ともこ）・党派・全ブロックの本文は、画像と文字単位で一致。ブロックの抜けなし。年齢の記載はなく age の null は正しい。slogan は基準に合う。b03の「域地から」「課題、問題を…実現する為に」、b02の「勤めて」は紙面どおりで、誤記ではない。以下は kind の基準のずれ。
- b02：「…全力で勤めて参りました。」を profile としている。c002 の b09・b10（「政策実現につなげてきました」「寄りそってきました」）は同じ種類の活動報告だが policy で、扱いがずれている。意見：具体的な政策内容がないので policy にはせず、c002 側を見直すか、この b02 を message にするかを揃えるのがよい
- b19：「多様性を認め合い人権が尊重される松戸市に！」を message としている。c007 b05（「民間にできることは、民間に。」）は同じく具体策のない短い文だが policy で、扱いがずれている。意見：message のままで c007 側を揃えるのが基準に近いが、「人権の尊重」を政策の主張と読むなら policy もありうる
## 分類の食い違い
問題なし（全14ブロックでA・Bのテーマと achievement が一致）
## 要約の問題
40字超過なし。「実績：」の付加なし。
- b14（A・B）：原文は「横断歩道等、道路区画線の引き直し」と読点で並べているが、A「横断歩道等の道路区画線の引き直し」、B「横断歩道等の区画線引き直し」は「の」でつなぎ、意味が変わる可能性がある。原文どおりの読点に戻すのがよい
- b15（A・B）：「高齢者・障がい者の」は本文になく、見出しから補ったもの（notes に記載あり）。見出しは就労支援の対象を明言していないため、高齢者も対象とするのは解釈になる。本文どおり「就労支援や体制づくり」にするのがよい
## 人に判断してほしいこと
- b20：字が小さく確信が持てない箇所。「旭町」「鶴田会」「防犯パトロール」（「パ」の半濁点）、「明第2西地区」、「監事」。私の読みは書き起こしと同じだが、原寸でも断定はできない
- b20：「松戸市議会議員団」と「会派経理責任者」は別々の「・」が付いて見えるので、書き起こしどおり別項目としてよさそうだが、続けて1つの役職と読むつもりの原稿の可能性はある。確認を（直す場合も紙面の表記どおり）
- career：`松戸市議会議員・1期4年間` は語句として紙面どおり。c007 は `松戸市議会議員1期`、c005 は `現職３期`。「4年間」まで含める範囲でよいかの確認
- b06：A・Bとも kosodate と bousai で一致しているが、窓枠の落下防止は bousai の基準（災害対策・防犯・交通安全・通学路など）に直接は書かれていない。kosodate だけでもよいかの確認
