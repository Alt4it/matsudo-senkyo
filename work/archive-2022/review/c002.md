# c002 照合結果
## 書き写しの問題
- b08（kind）：「マニフェスト大賞を10回受賞」は受賞歴で、政策の内容がない。`policy` ではなく `profile` が基準に合う。A・Bとも other／low としており、分類しにくさとも一致する。
- b09・b10（kind）：「政策案を、具体的な政策実現につなげてきました」「身近な問題に寄りそってきました」は活動全般の説明で、具体的な政策が書かれていない。`message` が合うと考える（A・Bとも other／low）。b10 は「トイレ」に触れるが施策は示していない。`policy` のままだと c002 の政策件数と「その他」の件数が増える。

（kind を変える場合、b08〜b10 は A・B の分類から外れる。氏名・年齢・党派・career・b01〜b15の本文は画像と文字単位で一致。ブロックの抜けと他の候補者の文章の混入なし。kana は姓の読みが紙面にないので null で基準どおり）
## 分類の食い違い
- b02：achievement が A=false（low）／B=true（low）。テーマは一致。（意見：文末が「洋式になります！」で2023年度末という先の時点を指し、schema の例「導入！」「削減できました！」のような過去の書き方ではないので、A の false が基準に合う。「そして、ついに」を成果と読む B の見方もあり、決定は人に委ねる）

（他のブロックはテーマ・achievement とも一致）

問題なし
## 人に判断してほしいこと
- slogan：b01「関根ジローは学校トイレの洋式化を推進してきました。」を採っている。b02「2023年度末、…洋式になります！」とほぼ同じ大きさに見え、どちらが大きいか画像からは断定できない（同じ大きさなら上にある b01 で基準どおり）。帯の「関根ジローはNO！選挙カー」はより大きく見えるが、見出しとして除外している。この扱いでよいか確認してほしい。
- b12（kind）：選挙カーを使わないという記述を `message` にしており、A・Bの分類の対象外になっている。候補者自身の選挙運動の話なので message でよいと考えるが、書き写し担当も迷っている点なので確認してほしい。
- b15：党名ロゴの文字を `other` のブロックにしている。c003 b16 も同様だが、c001 の党名の帯にはこのブロックがない。公開内容には影響しないと思われるが、揃えるか決めてほしい。
