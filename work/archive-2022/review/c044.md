# c044 照合結果
## 書き写しの問題
- b10：kind が policy だが、紙面の文は「みのわ信矢はこれまで、殺処分寸前の犬や猫とともに暮らしてきました。」で候補者個人の経験の説明。政策・公約・実績ではないので profile または message が基準に合う（文字の誤りはなし）。変更すると A・B の b10 は分類対象から外れる

## 分類の食い違い
問題なし（全13ブロックでテーマ・achievement とも A・B が一致）

## 要約の問題
- b08（A・B共通）：「大地震や集中豪雨、台風や真夏の高温」は原文の体言止めのままで、単独では何を言うのか読み取れない。言い換えで補うと原文にない内容になるため、要約を付けず原文だけにするか検討してほしい
- b14（B）：原文の「市民とつながる政治を実践しています」が「市民とつながる」に変わり、「政治を実践」が落ちている。A の「市民とつながる政治を実践している」の方が原文に近い

## 人に判断してほしいこと
- b15：「議会改革」はイラストの3輪バイクの旗の文字で、説明の文はない。同じイラストの「3輪バイクがトレードマーク！」（b16）は message なので、短い訴えとして message に揃える案がある。一方「議会改革」は行財政の基準にある語で、政策の項目とも読める。意見は message 寄り
- b14：「3輪バイクで市内を駆け回り」は活動の説明だが、「宗教や利権団体に縛られない政治を行うため」という姿勢の表明でもあり、見出し「…政治を実践します！」の配下にある。policy のままでよいか確認してほしい
- b07：A・B とも achievement=true で一致しているが、主語は「松戸市」で候補者自身の実績とは書かれていない（文末は「実現しました」）。両者とも confidence=low。候補者の実績の印を付けてよいか確認してほしい。意見は、印を付けると候補者の実績と読まれるため false 寄り
- b12〜b14：A・B とも other で一致しているが confidence=low。政治姿勢の話で、行財政の基準（議会改革・情報公開など）には語としては当たらない。other でよいか確認してほしい
