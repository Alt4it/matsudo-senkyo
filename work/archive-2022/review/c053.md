# c053 照合結果
## 書き写しの問題
- b12〜b14（kind）：見出し「市民の声を葬る市議会」の下の「市議会の仕事です」「などを提案」「否決されています」は議会活動と経過の説明で、b13 の①〜⑤に主張を含むものの、政策・公約・実績としては扱いにくい。message が基準に近いと思う。ただし、同じ形式の c051 b12〜b15、c050 b11〜b13 と揃えて判断すること。
## 分類の食い違い
- b13：A=other, gyozaisei / B=other（achievement は同じ false。意見：①〜⑤の内容は議会改革や行政の話ではなく、市議会での提案という形式だけで gyozaisei を付けることになるので、B が基準に合う）
## 要約の問題
- b13（A）：①②だけを残し、③木更津駐屯地へのオスプレイ配備やめよ、④性急な改憲やめよ、⑤核兵器禁止条約の批准を、が「など」に吸収されている。原文の「など」は①〜⑤の後に続くもので、並列の関係が変わっている。特定の主張が読者に見えなくなるので、公平性の面でも問題がある。
- b13（B）：「オスプレイ・性急な改憲やめよ」は③と④を1つにまとめており、並列の関係が変わっている。「木更津駐屯地への」「配備」「減らない」「時給」と原文の「など」が落ち、「最賃」は原文にない略語である。ちょうど40字で余裕もない。A・B とも要約に無理があるので、CLAUDE.md の「迷ったら要約せず原文だけにする」に従い、原文のみの表示を勧める。
- b10（A）：「段差を管理者(市)の責任と追及」としているが、原文で責任を問うているのは「〝転んでケガ〟」で、段差そのものではない。
- b10（B）：「市の責任と追及し」では、何の責任かが読み取れない。「〝転んでケガ〟」「管理者」が落ちている。
## 人に判断してほしいこと
- name：氏名欄に大きく書かれているのは「ミールかずえ」で、transcript の name はこれと一致する。「計恵」は「かずえ」の右に小さく添えられた字で、ほかに QRコードの説明「ミール計恵 HP」にある。name は「ミールかずえ」でよいと思う。「計恵」は issues にしか残らないので、サイトに併記するか判断してほしい。
- kana「ミールかずえ」：schema.md どおり氏名のかな部分をつないだものだが、カタカナを含む。五十音順の並びに影響する場合は、ユーザーが選管の資料などで確かめて sort_kana を入力する必要がある。
- b09「松戸に児童相談所新設(2026年度開所予定)」：A・B とも achievement=true（confidence は A=high / B=low）。見出しに従えば基準に合うが、開所前の事項に実績の印を付けてよいか判断してほしい。
- b07「ジェンダー平等の社会を」：◉の箇条ではなくイラスト上の枠内の文言で、具体的な施策のない短い訴えである。policy のままか message にするか判断してほしい（c052 b03 と同じ論点）。
- b10：箇条に小さい字の補足2文を含めて1ブロックにしている。補足は箇条の説明なので1ブロックでよいと思うが、文単位の区切りの例外としてよいか確認してほしい。
- b12・b14（kind を policy のまま残す場合）：A・B とも gyozaisei。議会改革の主張ではなく、見出しからの判断なので、other も考えられる。
- b15「コロナも物価高騰も無策／岸田自公政治ノー」：書き写し担当が kind の確認を求めている。政治批判の訴えなので message でよいと思う（c050 b14、c051 b16 も同じ扱い）。slogan も基準どおりと見る。
