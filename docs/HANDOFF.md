# 引き継ぎメモ（2026-11-06 時点）

claude.ai での相談内容をまとめたもの。計画書（Claude Docs）：https://claude.ai/artifact/GVpzzNEK6niEJsg66MGX83

## 1. きっかけと目的

- 松戸市議会議員選挙（告示 2026-11-08、投票 2026-11-15、定数44）。前回2022年は64人が立候補。
- 候補者情報が街頭演説とチラシに偏っている。選挙公報は候補者ごとに形式がばらばらで比べにくい。
- 目的：公報を**共通テーマ・共通形式**に整理し、有権者が同じ物差しで比べられるサイトを作る。評価・推薦はしない。

## 2. 決定事項

- **今回（11/15投票）**：公報を整理する方式で、小さく公開する。対象は公報のみ。
- **次回以降**：全候補に同じ質問を送る「共通アンケート方式」へ広げる（2027年春の千葉県議選で試す想定）。
- **作業方法**：Democracy Club（英国）型の「公式資料を書き起こして二重チェック → ロックして公開」。人手の代わりにClaude Codeのサブエージェントを使い、**最終確認はユーザー本人**が行う。
- **担当の粒度**：候補者1人に1体ではなく、書き写し担当1体あたり約5人。
- **分類**：2体（A/B）が独立にテーマ付けし、食い違いは照合担当が一覧にして人が決める。
- **サイト**：3画面（スローガン一覧／テーマ別に比べる／候補者から見る）。要約には公報原文を必ず併記。並び順はシャッフル・届出順・五十音順を選べ、初期表示はシャッフル。

## 3. 試作サイト

- `site/index.html`（claude.ai で作った試作版。架空データ6人入り）。データは `site/data.js` から読み込む形に改修済み。
- テーマ（仮・7つ）：子育て・教育／福祉・医療／まちづくり・交通／防災・安全／行財政／経済・産業／環境。`data/themes.json` で確定させる。

## 4. 参考事例（詳細は計画書）

- 海外：VOTE411（米、全候補に同じ質問・原文掲載・無回答は空欄）、Who Can I Vote For?（英、ボランティアが自治体PDFを書き起こし二重チェック）、smartvote（スイス）、StemWijzer（オランダ）
- 国内：マニフェストスイッチ（早大マニフェスト研、統一5項目）、大磯町議選の市民団体アンケート（4項目×120字、全員回答）、地方紙の候補者アンケート、選挙ドットコム投票マッチング（首長選中心）

## 5. 法律・倫理面（法的助言ではない。最終的には松戸市選管に確認）

- ウェブサイトでの発信は何人も可能（公選法142条の3）。全候補を同条件で扱う中立的なまとめは選挙運動に当たりにくいと考えられる。サイトに運営者の連絡先を表示する。
- してはいけない：ページを印刷して配る、有権者へ電子メールで一斉案内する、当落予想・人気投票の公表。
- 公報の転載・引用の範囲は選管に確認する。
- ユーザーが公立学校教員である場合は政治的行為の制限があるため事前確認。学校・生徒は関わらせない。
- AIの読み取り誤り（氏名・スローガン）は候補者に不利に働きうる → 人の照合なしに公開しない。
